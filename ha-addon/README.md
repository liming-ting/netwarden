# netwarden (Home Assistant add-on)

An AI home-network manager that runs next to Home Assistant: it finds the devices on
your network, watches which internet services each one talks to (through AdGuard Home
or Pi-hole, which you already run) and explains it in plain language.

- **Read-only.** It never changes your router, firewall, AdGuard Home or Pi-hole; it
  suggests, you decide.
- **Private.** No telemetry. Nothing leaves your network unless you configure an AI
  model and ask it something.
- **In your sidebar.** Opens through Home Assistant ingress - no extra port, no extra
  password.

Version 0.1.0 is the first public release. See the **Documentation** tab for setup,
options and limitations.

Project page: https://github.com/liming-ting/netwarden
