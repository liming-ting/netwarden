# 家庭網路報告

[English](report.md)

把你家網路的情況整理成一份白話摘要,可以存起來、印出來,或傳給幫你處理電腦問題的家人或朋友。
內容和儀表板用的是同一份資料。不需要 AI,也不會連到任何網路。

## 內容

- **家庭網路分數**:0-100 分、哪些項目扣分,以及趨勢。
- **建議**:前幾項建議和步驟。最多列出 8 項,其餘的留在儀表板裡。
- **裝置**:各類型的數量、這段期間新出現的裝置、還沒辨識的裝置。完整等級或保留名稱時,還會附上裝置表。
- **安全與隱私**:威脅、開放連接埠、DNS 盲點等發現,以及隱私等級。
- **網路健康**:這段期間的斷線紀錄,以及最近 7 天每天的 DNS 回應量。
- **重要事件**:這段期間值得注意的事。

期間可選 **7 天**(預設)或 **30 天**。圖表直接畫在檔案裡(SVG)。

## 隱私等級

| 等級 | 會顯示 | 會隱藏 |
|---|---|---|
| **可分享**(預設) | 分數、建議、裝置、發現、網路健康、事件 | MAC 與 IP 位址、原始網域(改成服務名稱,例如「YouTube」)、可複製的過濾規則。裝置名稱換成類型(「手機 2」),家人換成角色(「孩子 1」、「家人 2」),除非你選擇保留名稱(保留的名稱裡若含有位址或網域,例如 `nas.example.org`,那一段仍會換成 •••)。 |
| **精簡** | 只有分數和建議 | 和「可分享」相同。名稱一律替換,不能選擇保留。 |
| **完整** | 全部,包含 MAC/IP 位址和過濾規則 | 不隱藏任何網路資料。 |

被隱藏的值會顯示成 `•••`。房間名稱在每個等級都會保留。

任何等級都不會包含 API 金鑰、權杖、配對碼、密碼或設定的伺服器網址。報告根本不會讀取這些資料。

## 怎麼產生

**儀表板**:打開 **總覽 > 報告**,或按 `g` 再按 `r`,或在指令面板(Ctrl+K)輸入「報告」。
選好期間、隱私等級、名稱、家人和格式,再按 **預覽**、**下載** 或 **複製為 Markdown**。

**命令列**:

```bash
python3 -m netwarden report                          # 7 天、可分享、HTML、預設語言
python3 -m netwarden report --period 30d --privacy minimal --lang en
python3 -m netwarden report --privacy shareable --names keep --people keep --out home.html
python3 -m netwarden report --format md --out -      # Markdown 輸出到螢幕
```

預設檔名會帶日期,例如 `netwarden-report-2026-10-24-7d-shareable.html`。
`--out` 的檔名以 `.md` 結尾時,會改用 Markdown 格式。

**API**:`GET /api/report?period=7|30&privacy=full|shareable|minimal&names=type|keep&people=roles|keep&format=html|md&lang=<code>`
會以下載檔案的方式回傳報告。加上 `inline=1` 則直接在瀏覽器裡顯示。選項不正確時,會回傳已翻譯的 400 錯誤。

## 手機 / 區域網路模式

配對的手機(或任何非管理員的連線)可以下載 **可分享** 和 **精簡** 報告。**完整** 報告需要管理員權限:
也就是在執行 netwarden 的那台電腦上操作,或使用管理員配對(`pair --admin`)。否則伺服器會回傳 403。

## 檔案本身

- 單一 HTML 檔,CSS 都在檔案裡。沒有程式碼,也不會從任何地方載入字型或圖片
  (由內容安全政策 CSP 阻擋),離線也能打開。
- 可以印在 A4 或 Letter 紙上,每個段落從新的一頁開始。螢幕上會跟著你的淺色或深色主題,列印時一律是淺色。
- 頁首會標出日期、期間、隱私等級、netwarden 版本和原始碼網址。
- 資料相同、選項相同時,產生的檔案也完全相同。

## 限制

- 和儀表板一樣,所有內容都是根據 DNS 與掃描資料做出的 **估計**。
- 安全發現只看最近 24 小時,30 天的報告也一樣,因為警示就是以這個時間範圍計算的。斷線紀錄和事件則涵蓋整段期間。
- 隱私處理會隱藏 netwarden 知道的所有名稱、MAC 位址和 IP 位址,以及任何看起來像 IP 位址或網域的文字。
  但它沒見過的名字仍可能漏掉,例如裝置自己廣播的型號文字裡剛好有家人的名字。分享前請先看過一遍。
- 路由器的廠牌和型號在每個等級都會保留,方便幫忙的人找到對應的說明書。
